## About the Project

**TaskFlow** is a modern task management platform
designed to help people organize their daily activities,
manage tasks and improve productivity.

Our goal is to make task management simple,
convenient and efficient.

## Features

- Create and manage tasks.
- Organize daily activities.
- Set task priorities.
- Track task completion.
- Simple and user-friendly interface.

2. Open the project folder.
